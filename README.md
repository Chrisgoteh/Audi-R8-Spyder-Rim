## Files

| Format | Use |
|---|---|
| `.blend` | Original Blender file |
| `.glb` | Web and AR viewers, previews in GitHub |
| `.fbx` | Game engines and other 3D software |
| `.obj` + `.mtl` | Universal mesh format with materials |
| `.stl` | 3D printing |

# Audi R8 Spyder Rim | 3D Modelling Project

![Isometric View](Audi%20R8%20Spyder%20Rim%20-%20Isometric%20View%20.jpg)

A 3D modelling project inspired by the Audi R8 Spyder wheel design, developed using Blender.

The project demonstrates 3D modelling, geometric detailing and digital product visualisation, with consideration for manufacturable geometry.

## Downloadable Files

The project includes the following 3D model formats:

- BLEND – Native Blender project file.
- STL – 3D printing and mesh-based applications.
- OBJ – 3D geometry exchange.
- FBX – 3D asset interchange.
- GLB – 3D model visualisation and web applications.
- MTL – Material information associated with the OBJ file.

# Software and Tools

- Blender – 3D modelling and visualisation.
- Mesh modelling and geometric detailing.
- 3D asset export and file conversion.

## Approach

- **Modelling:** [i modelled one spoke segment and used alt + E to spin]
- **Reference:** [i worked from: blueprints]
- **Materials and rendering:** Dark steel-alloy material (Principled BSDF, base colour #727272, Metallic 1.0, Roughness [0.120]), rendered in [Cycles] with [Hdri].
